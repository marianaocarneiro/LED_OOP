# LED OOP 

**Object-Oriented Programming (OOP)** concepts by controlling LEDs.

## Features & Methods

The `LED` class provides the following core methods:

- `begin()`: Initializes the LED pin configuration.
- `update()`: Updates non-blocking LED state logic.
- `turnOn()`: Turns the LED on.
- `turnOff()`: Turns the LED off.
- `startBlinking(interval_ms)`: Starts blinking the LED at a specified interval (default: 500 ms).
- `stopBlinking()`: Stops the blinking effect.
- `toggle()`: Toggles the LED state (ON to OFF, or OFF to ON).
- `getPin()`: Returns the assigned pin number.
- `getState()`: Returns the current state (`true` for ON, `false` for OFF).
- `setState(state)`: Sets the LED state directly.
